# db: 192.168.56.10

## PostgreSQL
```bash
sudo apt update
sudo apt install -y postgresql
ls /etc/postgresql   # wersja: 16
```

## Użytkownik i baza
```bash
sudo -u postgres psql -c "CREATE USER app WITH PASSWORD '<haslo>';"
sudo -u postgres psql -c "CREATE DATABASE appdb OWNER app;"
```

## Schemat
Z Windowsa:
```powershell
scp db/schema.sql student@192.168.56.10:/tmp/
```
Na db:
```bash
psql "postgresql://app:<haslo>@localhost/appdb" -f /tmp/schema.sql
```

## Nasłuch na sieci
`/etc/postgresql/16/main/postgresql.conf`:
```
listen_addresses = 'localhost,192.168.56.10'
```

## Dostęp tylko z backendu
Na końcu `/etc/postgresql/16/main/pg_hba.conf`:
```
host  appdb  app  192.168.56.11/32  scram-sha-256
```
```bash
sudo systemctl restart postgresql
sudo ss -tlnp | grep 5432   # 192.168.56.10:5432
```

## Firewall
```bash
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow OpenSSH
sudo ufw allow from 192.168.56.11 to any port 5432 proto tcp
sudo ufw enable
```
